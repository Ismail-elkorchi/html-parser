# Support

Open a GitHub issue for usage questions and reproducible bugs. Include:

- the installed package version and runtime;
- a minimal HTML input and code example;
- the result you expected and the result you received.

Do not post suspected vulnerabilities publicly. Use the private process in
[SECURITY.md](./SECURITY.md).

html-parser builds an immutable HTML tree and deterministic utilities around
it. It is not a browser DOM, script runtime, layout engine, or sanitizer.
